# 预测走势前端设计

## 页面定位

把「预测走势」做成行情页的研究工作台。用户选股后直接看到日 K 图、分析操作和结果，查看某条判断时能回到所依据的交易日。

沿用项目行情页的全局导航、紧凑网格、面板边框、表格、主题变量和 A 股涨跌配色。参考 PA Agent 的顶部操作条、左图右栏、分析进度条，以及将「下一根 K 线」和「下一阶段走势」分块展示的方式。开发时复用项目的 `StockSearch`、`KLineChart` 和响应式基础样式。

## 桌面布局

| 区域 | 内容和交互 |
| --- | --- |
| 顶部操作条 | 股票名称、代码、搜索框、日线标识、数据截止日、「开始分析」、自动跟踪。运行中原位显示进度，错误后提供重试入口。 |
| 左侧主图 | 约占可用宽度的三分之二。显示 K 线、成交量、十字线和现有指标控件。支持「最新行情」与「分析快照」切换。 |
| 右侧结果栏 | 「预测结果」「历史回放」两个标签页。预测页依次显示市场诊断、下一根方向、下一阶段类型和对应证据。历史记录选择器、模型和数据版本归入结果详情。 |

预测卡片用文字和图标同时表达「涨」「跌」「平」「无法判断」，下一阶段显示走势类型和观察窗口。旧记录显示其原有窗口口径。分析过程映射现有任务状态，依次展示等待、诊断、推演、完成或失败。

## 图表与结果联动

- 查看分析记录时，提供切换到该记录快照的入口。点按证据条目后，图表跳到相应日期并高亮该根 K 线。证据条目显示交易日、字段、值和解释。
- 最新行情与分析快照分别标注来源、日期及当前图表模式。快照模式使用该次分析保存的已收盘序列。首屏加载最新行情，按需加载快照。
- 当前运行列表只返回快照元数据。历史记录的图表联动需要按记录 ID 读取其存档日线，并复用该记录的访问权限校验。未取得快照时，结果栏仍可阅读诊断和证据列表。

## 历史回放

在「历史回放」页签填写截止日、样本数和数据口径。任务提交后显示队列和处理进度。先展示方向和走势各自的命中率、覆盖率及分子分母，再展示共同样本上的 AI 与基线对照。逐日结果用表格显示预测、实际结果、观察截止日和缺失原因，点击日期可定位图表。

## 移动端

沿用行情页的安全区、触控尺寸和面板切换方式。767px 及以下采用单列布局，操作条分行，图表全宽，预测与回放放在图表下方。较矮的触屏横屏优先保留图表高度，可点按切换「图表」「结果」。宽表在独立容器内横向滚动，证据定位和结果切换都提供可点按入口。

## 实施顺序

1. 复用行情页外壳、选股和图表，跑通未选股、加载中、无数据、加载失败四种状态。
2. 接入预测状态、诊断卡片、两种预测结果、历史记录和自动跟踪。
3. 接入历史快照读取与证据定位，验证行情切换时保持正确的股票、记录和图表日期。
4. 接入回放报告和同样本基线，覆盖手机竖屏、触屏横屏和桌面布局。
