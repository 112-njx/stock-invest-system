优化6：行情详情页技术指标加载性能优化。
（1）K线与技术指标当前为串行加载（loadKline 中先 await fetchKLine，设置数据后再 await fetchIndicators），总等待时间 = K线请求时间 + 指标请求时间。改为 Promise.all 并行请求：K线数据到了先渲染主图，指标数据到了再渲染副图，总延迟降为 max(T1,T2)。
（2）切换标的时，若新标的与旧标的相同且周期未变，可复用已加载的指标数据，避免重复请求。
（3）指标 pane 重建时保存并恢复 timeScale 的 visibleLogicalRange，避免切换指标显示后缩放位置被重置（当前 toggleIndicator 已做此优化，需确认切换标的/周期时也保留）。
（4）首页 F 区单击切换标的时，可预加载下一个可能查看标的的指标数据（watchlist 中的标的），进入详情页时秒开。
