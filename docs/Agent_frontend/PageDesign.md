# 前端页面设计文档

> 对应 docs.md 页面需求，按页面/区分类说明。核心约束：前端只渲染，复杂指标一律后端算。
> 布局参照 docs.md ASCII 图；主题默认暗黑；K 线用轻量级图表库（lightweight-charts）。

## 页面总览（路由）
| 路由 | 页面 | 说明 |
|---|---|---|
| `/login` | 登录/注册 | 首次进入 |
| `/market` | 行情页·第二层 | 默认首页 E/F/G/H/I 区 |
| `/market/detail` | 行情页·第一层 | 双击个股/ETF/指数进入 A/B/C/D 区，Esc 或左上角按钮退出 |
| `/ai` | AI 策略页 | J/K/L/M/N 区 |

全局状态（Pinia）：`userStore`（token/头像/昵称）、`themeStore`（暗黑/明亮）、`marketStore`（当前标的/实时快照缓存）。

---

## 一、登录/注册页（/login）

- **功能**：登录/注册 Tab 切换；注册（用户名/密码/确认）→ 登录（用户名/密码）。
- **数据**：`POST /api/v1/auth/register`、`POST /api/v1/auth/login`；成功后存 token 跳 `/market`。
- **交互**：表单校验、错误提示；登录态由 API 层 token 注入保证。

## 二、行情页·第二层（默认首页 E/F/G/H/I 区）

```
┌──────────────────┬──────────────────────────────┐
│ E 重点关注股票列   │ F 单击K线图                    │
│                  │                              │
├──────────────────┼───────────────┬──────────────┤
│ G 大盘指数列表     │ H 行业指数列表  │ I 设置/开发者  │
└──────────────────┴───────────────┴──────────────┘
```

### E 区 · 重点关注股票列
- **功能**：显示用户重点关注的股票列表，每行：股票代码、名称、最新价、涨跌幅（红涨绿跌）。
- **数据**：`GET /api/v1/watchlist`（返回合并实时价）；实时价轮询刷新。
- **交互**：行点击 → F 区切换该标的 K 线；支持添加/删除。
- **组件**：复用 `WatchlistPanel`（与第一层 D 区共用）。

### F 区 · 单击 K 线图
- **功能**：显示 E/G/H 区当前点击标的的 K 线图，UI 与第一层 A 区一致。
- **数据**：`GET /api/v1/kline?symbol=&period=1d`。
- **交互**：E/G/H 行点击联动切换；双击 K 线图进入第一层详情页。

### G 区 · 大盘指数及机会指标（固定 14 项）
- **列表**（固定顺序）：上证指数、沪深300、创业板指、科创50、深证成指、上证50、中证1000、中证2000、日经指数、韩国综合、道琼斯指数、纳斯达克指数、标普500、现货黄金。
- **每行**：指数名称、最新价、涨跌幅、关联 ETF、机会指标（本版置空）。
- **数据**：`GET /api/v1/symbols?type=index&is_fixed=1` + snapshot，按 `sort_order` 排序与区分大盘/行业。
- **交互**：行点击 → F 区联动；列表可上下滚动。

### H 区 · 全行业指数及机会指标（固定 35 项）
- **列表**（固定顺序，同 docs.md 35 个行业）：通信设备、半导体、元件、游戏、教育、半导体设备、光学光电子、软件开发、消费电子、创新药、商业航天、电网设备、文化传媒、军工、机器人概念、电池、工业金属、光伏设备、贵金属、消费、细分化工、油气开采及服务、电力、证券、工程机械、农业种植、房地产、煤炭开采加工、猪肉、白酒、港口航运、公路铁路运输、汽车整车、保险、银行。
- **每行**：同 G 区；数据源同上，前端按配置分组大盘/行业。

### I 区 · 通用设置与开发者信息
- 上部：用户头像及名称（登录信息）。
- 中部左边：软件设置；中部右边：显示风格设置（暗黑/明亮，默认暗黑，即时切换并持久化）。
- 下方：开发者信息「本软件由 Xhope(发誓不做夜猫子)全程开发」。

## 三、行情页·第一层（双击进入 A/B/C/D 区）

```
┌──────────────────────────┬───────────────┐
│ A 区域（K线图）            │ C 基本数据      │
│ B 区域（技术指标）          │ D 重点关注列表  │
└──────────────────────────┴───────────────┘
```

### A 区 · K 线图
- **功能**：个股/ETF/行业指数/大盘指数 日K、周K、月K、15minK 显示。
- **数据**：`GET /api/v1/kline?symbol=&period={15m|1d|1w|1mon}`。
- **交互**：周期切换 Tab；支撑/压力位横线叠加；双击进入、Esc/左上角退出（返回第二层）。
- **组件**：`KLineChart`（第一层/第二层 F 区共用）。

### B 区 · 技术指标
- **功能**：成交量、成交额、MACD、KDJ 指标显示（后端算好，前端渲染），与 A 区 K 线联动。
- **数据**：`GET /api/v1/indicators?symbol=&period=`。
- **左上角设置键**：弹窗输入股价支撑位/压力位 → `POST /api/v1/support-resistance` → A 区 K 线叠加相应横线。

### C 区 · 基本数据
- **通用字段**：标的名称、代码、当前价格、涨跌额、涨跌幅、昨日收盘、今开、最高、最低、成交量、成交额、换手率、振幅、更新时间。
- **特殊字段（按类型）**：
  - 股票：总市值、PE。
  - ETF：溢价。
  - 指数：指数总 PE。
- **数据**：`GET /api/v1/snapshot?symbols=`（+ fundamentals/etf_premiums/index_valuations）。

### D 区 · 重点关注股票列
- 同第二层 E 区，共用 `WatchlistPanel`。
- **搜索栏**：仅 A 股 6 位数字代码搜索添加；对已入库标的实时联想提示（`GET /api/v1/symbols/search`）。

## 四、AI 策略页（/ai · J/K/L/M/N 区）

```
┌──────────────────┬──────────────────────────────────────┐
│ J 聊天记录侧边栏   │ K AI主操作区（标题介绍）                 │
│                  │ L 快捷功能卡片区（卡片+输入区）           │
├──────────────────┼──────────────────────────────────────┤
│ M 交易策略+记忆   │ N 交易策略显示区（点击 M 中策略时替换 K+L） │
└──────────────────┴──────────────────────────────────────┘
```

> 高仿 QuantDinger 分区架构；J 列竖直固定，K+L 与 N 互斥切换。

### J 区 · 会话列表侧边栏
- 顶部「策略/聊天」标识作为切换入口（默认聊天页）；当前所在页标识底部呈现浅白色圆角矩形背景。
- 聊天页：历史会话列表（`GET /api/v1/conversations`），点击加载消息；新建会话。
- 策略页：交易策略列表入口（点击切 N 区，见 M 区）。

### K 区 · 顶部标题介绍
- 中部居中：图标、主标题《定制你的交易Agent》、辅助小字「询问市场情况，解释日志，定制策略，永久记忆」。

### L 区 · 快捷功能卡片 + 输入区
- **功能卡片（两行三列）**：
  - 第一行正中间：「创建交易策略」（小字：描述一个入场想法，AI 会补齐规则和风控）。
  - 第二行三列：「诊断符号」（趋势、动量、支撑/阻力、流动性和风险）、「交易计划」（把当前行情整理成可执行的交易检查清单）、「机会雷达」（密切关注未来 24 小时内可能出现的机会）。
- **点击行为**：将对应 prompt 模板写入下方对话框（模板见 docs.md 4.1/4.2/4.3）；「创建交易策略」额外插入策略模块（见下）。
- **标的选择行**：文字提示「选择要分析的标的」+ 下拉框（股票/指数/ETF 名称 + 类型）。
- **大文本输入框**：背景示例引导「例如：帮我分析一小时内上证指数的趋势……」。
- **底部操作栏**：左侧风险提示「风险提示：AI 输出仅用于研究参考，不构成投资建议。决策前请自行核对数据、风险和仓位。」右侧「发送」按钮。

#### 创建交易策略模块（点击「创建交易策略」后插入）
- 三层垂直布局：
  - 顶层：折线图标 + 标题「你希望策略怎么交易？」+ 提示标签「可直接发送」。
  - 中层：说明文字「不需要写代码。可以直接发送，也可以点选你最关心的规则。」
  - 底层：横向并列按钮「+ 入场规则」「+ 止损止盈」「+ 仓位管理」。
- 同时在标的选择行下方增加一行「我不选择标的，我思考的是通用的交易体系」。
- **按钮追加规则**：入场规则→「使用清晰的入场条件，并避免在行情末端追涨杀跌。」；止损止盈→「加入稳健的止损和止盈规则。」；仓位管理→「加入简单的仓位管理，并限制每笔交易的最大风险。」

### M 区 · 交易策略和记忆文件
- **交易策略栏**：每行格式类似会话记录，保存用户交易策略（`GET /api/v1/strategies`）；点击某策略后 K+L 区切换为 N 区。
- **记忆文件**：按钮「记忆文件」→ 打开 Agent 在本地保存的记忆文件夹（由后端提供打开能力/返回本地路径）。

### N 区 · 交易策略显示区
- 所有文字居中；共四部分：
  1. **交易策略描述模块**：显示用户描述的该交易策略。
  2. **回测结果模块**：显示已保存的该策略回测结果。
  3. **代码实现模块**：展示/修改策略代码（可编辑保存）。
  4. **回测模块**：选择标的（股票/指数/ETF）→ 额外发起回测 → 保存回测结果。
- 回测跳转：AI 输出后的「回测显示」按钮 → 跳转 `/market/detail`，此时 **D 区替换为策略指标显示页**：策略胜率、盈亏比、夏普比率、累计买入、累计卖出、年化收益率、最大回撤（数据 `GET /api/v1/backtest/results?strategy=`）。

## 五、关键交互汇总
| 交互 | 动作 |
|---|---|
| 进入第一层 | 双击任一标的 K 线 / E·G·H 行单击后双击 |
| 退出第一层 | Esc 键 / 左上角退出按钮 |
| 主题切换 | I 区设置即时切换暗黑/明亮，持久化 |
| 搜索添加 | 6 位代码联想 → 添加关注 |
| 功能卡片 | 点击写入 prompt 模板 |
| 保存策略 | AI 输出下方按钮 → 入库 → M 区显示 |
| 回测显示 | AI 输出下方按钮 → 跳转第一层 + D 区替换策略指标 |
