【技术栈与硬约束】
- Vue3 + TypeScript + Composition API（`<script setup lang="ts">`）+ Pinia + Lightweight Charts + Tailwind CSS。
- 禁止组件内 setInterval 轮询，实时数据必须走 WebSocket/SSE → Pinia Store → 响应式更新组件。
- 深色主题专业金融终端风格：背景 #0B0E11/#111827，涨红跌绿，低视觉噪音，对标 TradingView/同花顺专业版，禁止圆角Card堆叠的Dashboard风格。
- 前端不计算复杂指标（MACD/KDJ等），全部后端计算，前端只渲染。
- 【前端界面固定约束】当前前端界面已经固定，V0.2只在现有界面基础上做体验优化和功能增强，不对UI组件、页面布局、路由跳转逻辑做过大修改。新增功能优先复用现有组件（如SSE处理复用现有src/api/ai.ts、回测结果卡片复用现有回测页组件、代码编辑器复用N区现有编辑器），如确需新增组件，在设计验证中说明为什么现有组件不能满足需求。
