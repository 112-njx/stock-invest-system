# 预测走势：日线快照和指标计算

`GET /api/v1/forecast/snapshot?symbol=600519` 返回 A 股个股的前复权日线快照。复用项目现有历史行情与来源优先级，每个快照只使用一个来源。响应包含行情截止时间、最后有成交的日线日期、来源、数据指纹、特征版本、历史总根数和最近 40 根日线的特征。

日线在上海时间 15:00 后重新取得才可进入预测。启用更新控制器时，StockDB 还要求原始数据的下载在对应日线收盘后启动，仅重新查询同一份文件不会确认日线。迁移保留既有历史，每只股票在各数据源的末根日线需要重新同步确认。预测和最近 K 线预览共用本地优先的来源选择。周末和无成交占位行会被排除，缺失交易日保留为空缺。历史不足 40 根时返回 `insufficient_history`。用 `latest_session` 查看最后一根可用日线，`closed_through` 表示时间截断上界。

Python 调用层统一使用 `sdk_indicators.calculate`，容器内同一 `/indicators/calculate` 入口按指标名分发。图表原有指标继续使用 `zhibiao` / `zb_core`。预测使用独立 Rust + PyO3 模块 `market_indicators` 的 `forecast_features`，可和原指标在同一请求中计算。指标目录和图表设置保持原有口径。

EMA20 以首 20 根收盘均值初始化，ATR14 以首 14 根真实波幅的均值初始化，之后分别使用指数平滑和 Wilder 平滑。量比以当前成交量除以前 20 根的平均成交量。突破相对前 20 根的高低边界，区分影线越界与收盘突破。局部波段高低点在右侧一根日线收盘时确认。支撑与压力从最近 40 根的已确认低点和高点中选取，回撤按最近一段可确认波段和当前收盘价计算。

Redis 按标的、来源、复权口径和特征版本保存计算状态。重复请求复用已算结果，行情只追加时只将新增 K 线送入原生模块。历史补录、删减或前复权重算导致旧数据指纹变化时全量预热。历史仍会重新读取和校验，用于识别任意日期的修订。当前前复权序列用于当前快照，历史评估时还需验证复权数据在当时是否可用。

Docker 和 Windows 的构建、加载方式见[本地行情数据源](local-market-sources.md#阶段-2统一指标入口)。

登录后可在「预测走势」手动提交分析。第一阶段诊断行情并引用快照中的日期和字段，第二阶段按诊断选规则，分别推演下一根日 K 线方向和下一阶段走势。下一根的涨跌以该根收盘价相对开盘价为准。两个结果可以分别弃权，引用日期、字段和值由后端核对。

分析记录保存完整输入快照、数据与特征版本、两个阶段的模型标识和供应商提供的版本指纹。每个账号同一时刻运行一项分析，手动和自动分析共享同一快照的记录。失败记录可从历史列表选中并按原快照重试。个人数据导出中的 `forecast.json` 包含分析记录和自动跟踪设置。

自动跟踪按个股开启，以开启时最后一根已确认日线为起点。仅开启预测跟踪的股票也纳入本地行情同步，补齐预测需要的日线。每日收盘同步由管理员启用，Free-StockDB 原始数据仍需更新。Celery Beat 每分钟安排检查，单个订阅完成检查后约五分钟再查。新日线累计不足四十根时保存「无法判断」并更新游标。

「历史回放」按时间正序分析截止日前的 1 至 10 根有成交日线，截止日留空时跳过最新五根以留出完整观察窗口。回放复用当前两阶段模型与指标库，存档口径使用原快照的特征版本。行情、标签规则、特征和模型版本随报告保存。回放在独立 Celery 队列执行。

- 重建历史从本地 Free-StockDB 读取原始日线和累计因子，以指定日期前约一年半作预热。每次仅将截止日及以前的日线和已生效因子用于模型输入，后续数据仅用于打分。数据源当前版本可能包含事后补录或修订。
- 当日存档只用本账号在该交易日收盘后实际保存的快照。缺失样本保留在覆盖率分母里。两种口径均使用当前可取得的实际结果。
- 下一根是标的后续首根有成交的确认日线。以原始收盘与当根开盘的关系判涨、跌、平，方向基线为沿用当根方向和恒猜涨。
- 下一阶段观察后续五根有成交的确认日线，规则 v1 用观察起点前 20 根（含起点）的最高、最低和最近 14 根真实波幅均值作为基准。若最后两根收盘同向越界且末根越界超过半个平均真实波幅，判突破。其余以净位移除以逐步绝对位移之和为效率。位移至少一个平均真实波幅、效率至少 0.8 为趋势。位移至少 0.75 个平均真实波幅、效率至少 0.65 为窄通道，效率在 0.45 至 0.65 之间为宽通道。其余为震荡。走势基线为沿用紧邻的历史五根按同一规则判得的类型。
- 方向和走势各自计算。命中率以给出明确结果的样本为分母，覆盖率以已有实际结果的样本为分母。弃权、模型失败和缺少快照均降低覆盖率。百分比是选定样本的经验频率，模型没有输出概率，也没有用这些样本校准概率。
