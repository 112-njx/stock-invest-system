# 全数据工作台

入口：菜单“大盘云图”后方的“全数据”，地址 `/all-data`。

选择类型、填写必要条件后点击“查询并保存”。进入页面、切换分类、冷却结束均不会请求在线数据。后台“数据源”中的“在线数据接口请求频率”可配置共享间隔，默认 30 秒，最小 30 秒；该配置只有管理员可修改。SQLite 事务预占请求时间，失败也计入冷却，配置和冷却跨进程、跨重启保存。

请求链路：前端 → FastAPI → 7900 SDK 桥 → 官方在线 SDK。没有自动重试、轮询远程行情或循环补齐数据。

查询成功后，原始数据及请求条件保存在 `D:\Free_stockdb\stockdb\mydb\在线查询\数据类型\股票或全市场_日期或报表期_获取时间.json`，使用现有 Docker mydb 绑定目录。空结果也保存，非有限浮点缺失值转换为 JSON null。保存失败时明确报告失败。目录下的 `请求频率配置.sqlite` 保存配置与冷却状态。

表格动态展示上游字段，每页 100 条，可导出当前完整结果 JSON。上游返回的代码或日期范围不符时，结果区明确提醒，原始返回不被静默修改。

查询参数按当前接口构造，非 Tick 接口不发送或校验条数。冷却按绝对截止时间计算，休眠或切回标签页时立即校正；可见性恢复只读取本地限频状态，不触发在线行情查询。在线查询专用代理超时为 200 秒，长于后端 180 秒等待时间，短于浏览器 210 秒等待时间；其他 API 的代理超时不变。

验证：`stock_backend/.venv/Scripts/python.exe -m pytest scripts/tests/test_stockdb_online.py scripts/tests/test_stockdb_sdk_bridge.py -q`；前端目录执行 `node scripts/verify-all-data.mjs` 与 `npm run build`。
