# 全数据工作台

入口：菜单“大盘云图”后方的“全数据”，地址 `/all-data`。

选择类型、填写必要条件后点击“查询并保存”。进入页面、切换分类、冷却结束均不会请求在线数据。后台“数据源”中的“在线数据接口请求频率”可配置共享间隔，默认 40 秒，最小 40 秒；已有低于 40 秒的配置自动提升到 40 秒，更长配置保留；该配置只有管理员可修改。SQLite 事务预占请求时间，失败也计入冷却，配置和冷却跨进程、跨重启保存。

请求链路：前端 → FastAPI → 7900 SDK 桥 → 官方在线 SDK。没有自动重试、轮询远程行情或循环补齐数据。

查询成功后，原始数据及请求条件保存在 `D:\Free_stockdb\stockdb\mydb\在线查询\分类\数据项目\股票或全市场_日期或报表期_获取时间.json`，使用现有 Docker mydb 绑定目录。空结果也保存，非有限浮点缺失值转换为 JSON null。保存失败时明确报告失败。目录下的 `请求频率配置.sqlite` 保存配置与冷却状态。

表格动态展示上游字段，每页 100 条，可导出当前完整结果 JSON。上游返回的代码或日期范围不符时，结果区明确提醒，原始返回不被静默修改。

查询参数按当前接口构造，只发送和校验当前接口使用的参数（连续多日财务接口也支持条数）。冷却按绝对截止时间计算，休眠或切回标签页时立即校正；可见性恢复只读取本地限频状态，不触发在线行情查询。在线查询专用代理超时为 200 秒，长于后端 180 秒等待时间，短于浏览器 210 秒等待时间；其他 API 的代理超时不变。

验证：`stock_backend/.venv/Scripts/python.exe -m pytest scripts/tests/test_stockdb_online.py scripts/tests/test_stockdb_sdk_bridge.py -q`；前端目录执行 `node scripts/verify-all-data.mjs` 与 `npm run build`。

## 扩展目录

根据公开文档（https://dns.novapi.cc/docs/index.html）整理，包含 21 类、83 个数据项目（15 个直接接口与 68 张查询表）。目录由 `scripts/stockdb_online_catalog.py` 和 `scripts/stockdb_online_tables.json` 统一定义，`GET /api/v1/all-data/catalog` 只读取本地元数据，不访问在线数据源。

包含因子值、期货主力、集合竞价、三大报表及财务指标、连续多日财务数据；融资融券分类集中提供交易数据和两种标的名单；基金补充接口仅提供净值类型。业绩、股东、公司事件、港股通、市场汇总、基金、债券、宏观、期货、期权与新闻均有独立数据项目。

查表支持最多10个条件同时满足、文本/数值/布尔值类型、比较/列表/模糊匹配、返回字段与排序、单次1至5000条。不会自动分页或循环拉取。只允许目录内的表；字段只能是安全标识符，已知字段按文档校验；新闻及宏观表文档缺少字段清单时允许手动填写字段名，由上游返回实际支持情况。无 eval 或任意查询代码入口。

目录可浏览与接口实际可用性分开：即使过去不可用也保留入口，手动点击后只请求一次；失败不保存成成功数据，仍计入共享冷却。期货主力可显示合约字符串，列表、嵌套字典、DataFrame/Series 可保存及展示，原始结果视图保留多维数据。

本次扩展通过替身 SDK 验证全部83个项目的参数构造和单次分发，未批量探测远程接口。此前实测结果不代表当前或新增接口的可用性。
