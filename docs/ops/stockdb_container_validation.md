## 性能与资源

容器观测工作内存约 122–227 MiB；cgroup `memory.peak` 为 663,400,448 字节（约 633 MiB，包含内核计费和文件缓存），上限 2 GiB，未 OOM。镜像大小约 194 MiB。此为样本负载结果，不代表全市场批量计算的内存上界，也不能直接换算为整机新增内存。

行业冷查询本轮比 Windows 慢约 37%–45%；绑定挂载、运行环境、缓存和系统负载均可能影响结果，未单独隔离磁盘因素。保留原桥串行锁：长查询会阻塞其他请求，缓存命中也需要等待该锁。本轮长历史并发请求耗时 77.48 秒，包含排队；月线缓存请求一度排队 44.56 秒，单独重测为 0.035 秒。未为迁移改变该行为。
